# 项目需求

## 目标
面向中国大陆新媒体平台，优先探索广告、带货或流量变现。首期只验证一个账号、一个垂直领域、一个平台。

## 闭环
1. 采集趋势与公开内容信号，记录来源 URL 和采集时间。
2. 以热度、受众需求、竞争优势、变现潜力评分。
3. 生成标题、正文、封面文案、标签和可选视频脚本。
4. 核查事实、来源、重复度和平台规则。
5. 进入人工审核；未批准不得发布。
6. 通过官方 API 或授权工具发布，保存内容 ID 和时间。
7. 记录发布后 1 小时、24 小时、7 天等时间窗口的数据。
8. 生成复盘并反馈下一轮选题。

## 首期非目标
- 不做多平台全自动发布。
- 不绕过验证码、登录保护或平台限制。
- 不自动投放广告或自动下单。
- 不承诺收益。
- 不在未核实账号资质和权限前假设平台 API 可用。

## 主要数据表（后续实现）
- topics：来源、趋势分、选题分、决策与状态。
- content_items：文案、素材、提示词/模型版本、审核状态、发布状态。
- content_metrics：统计时间、阅读/播放、互动、涨粉、转化和成本。

## 待确认
- 首发平台：微信公众号 / 抖音 / 小红书 / 其他。
- 垂直领域与目标受众。
- 图文还是短视频优先。

## 当前实现快照（2026-10-12）
- 已实现：FastAPI 健康检查、配置权重评分、SQLAlchemy 数据模型与 Alembic 初始迁移、RSS 2.0/Atom 公共 feed 解析/HTTPS 获取/按来源 ID 幂等入库。
- RSS 采集只保留来源 URL、来源标识、发布时间（如 feed 提供）和采集时间。Feed 通常没有可靠热度值，因此不补造趋势指标。
- RSS 条目不是社交平台内部趋势。首发平台、垂直领域和受众仍待确认；需在确认后选择公开授权数据源。
- 未实现：LLM 内容生成、事实核查与审核队列、发布适配器、发布后指标采集、分析和变现归因。
- 内容模型预留 AI 生成标记状态；真正生成/导出/发布前仍需按适用规则、平台要求和内容形态实现并验证标识流程。相关规则已自 2025-09-01 生效，不能把审核按钮本身当作合规保证。
- 模型/迁移/采集单测已添加，但本轮遵照用户要求没有执行任何命令，测试与依赖安装状态未验证。
